# 🌐 AWS S3 Static Website Hosting Project

## 📌 Objective

To host a static website using Amazon S3 and make it publicly accessible through a website endpoint URL.

---

## 🛠️ Tools & Technologies

* Amazon Web Services (AWS)
* Amazon S3 (Simple Storage Service)
* Static Website Hosting
* Bucket Policies
* AWS Management Console
* HTML & CSS

---

## 📂 Project Steps

### 1. Create S3 Bucket

* Created a bucket named **sathya-static-website-2026**
* Selected region: **Asia Pacific (Sydney)**
* Disabled Block Public Access to allow website hosting

---

### 2. Upload Website Files

* Created an `index.html` file
* Uploaded the website file to the S3 bucket
* Verified successful upload

---

### 3. Enable Static Website Hosting

* Enabled Static Website Hosting in bucket properties
* Configured `index.html` as the index document
* Generated the S3 website endpoint URL

---

### 4. Configure Public Access

* Added a Bucket Policy to allow public read access
* Granted `s3:GetObject` permission to all users
* Verified successful policy configuration

---

### 5. Access the Website

* Opened the S3 website endpoint URL
* Verified that the website is publicly accessible
* Successfully hosted a static website using Amazon S3

---

## 🎯 Outcome

* Successfully hosted a static website using Amazon S3
* Configured Static Website Hosting
* Implemented Bucket Policy for public access
* Accessed the website through a public endpoint URL
* Gained hands-on experience with cloud-based web hosting

---

## ⚠️ Key Learnings

* Amazon S3 can be used to host static websites
* Bucket names must be globally unique
* Static Website Hosting must be enabled explicitly
* Public access requires proper Bucket Policy configuration
* S3 website endpoints provide public access to hosted content

---

## 🚀 Conclusion

This project demonstrates practical knowledge of Amazon S3 Static Website Hosting, bucket configuration, public access management, and cloud-based website deployment. It provides hands-on experience in deploying and managing static web content using AWS cloud services.
